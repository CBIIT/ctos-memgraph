# ctos-memgraph

### Summary

This repository is to allow simple building of a Memgraph docker image to update any security issues on the base image. It currently is hard-coded to pull a version of Memgraph 3.12, but the latest version can be gotten at the [Memgraph direct download page]( https://memgraph.com/docs/getting-started/install-memgraph/direct-download-links)

The matching version of the Ubuntu image must be used (right now, we're using 24.04).
